# 原版驱动纯照射离线版本

基准为用户指定的 `VantageNXT-2.3.2-p2/XJD/SetUpP9_4TSICE_FlashAngles.m`。`SetUpP9_4TSICE_TXOnly_20mm_35V_offline.m` 调用原厂 `computeTrans` 和 `computeTXDelays`，保留原128收发资源配置、探头名及35 V软件上限、6 MHz `TW.Parameters=[6,.67,2,1]`、64元均匀加权。焦点改为阵面中心轴20 mm，TPC Profile 1请求35 V；电压为软件请求，不是负载实测。焦距按原 `Trans.frequency` 与 `Resource.Parameters.speedOfSound` 换算波长。

完全移除接收、重建、处理、显示事件、数据传输及原始无限跳转。沿用原始每组15次、30组与组内400 μs、组末14400 μs的请求时序，共450个TX事件及stop；原成像时间框架作为离线候选被保留，不证明无接收条件下硬件实际时序或充电充足。原波形为1个完整周期，名义burst约0.1667 μs；组内名义burst/PRI约0.0417%，请求间隔周期按600 ms计算的名义总burst约75 μs、占比0.0125%。与原成像脚本比较，停止替代循环，时间有限；不是连续照射。

强制 `simulateMode=1`，不调用VSX、不保存、不连接硬件。脚本使用base工作区：原厂 `computeTrans` 和 `computeTXDelays` 依赖base变量，仅应在独立MATLAB进程中构建。未验证VSX加载/波形量化、设备输出或实际停止行为，不是上机版本。无Receive对象不证明物理接收电路隔离。

35 V只是原代码上限而非厂家安全额定。探头在此波形下的电压、burst、重复频率、热限值和实际阻抗均unknown，50 Ω仅为原软件值；不能称本版本为最大安全功率，不能推导焦点MPa、温升、固化或临床安全。D00108 Rev.L §1.4 pp.8–9与§3.1 pp.15–17说明系统保护不保护探头，输出受负载及系统限制；D00107 Rev.K §4.4 pp.29–30区分成像供电及可选高功率供电；D00163 Rev.K §12 pp.95–97与p.A154说明TPC与波形参数；D00109 Rev.D §4.5 pp.9–10描述自检，本轮未执行。手册和本机厂商软件不保证跨电脑可用。

MATLAB R2024b独立进程测试 `tests/test_original_txonly_35v.m`：1/1通过，检查原波形、64元、35 V请求、焦点与几何延时、450 TX/1 stop、无成像对象及事件索引；Code Analyzer 0项。首次测试因缺少厂商 `System/P_Files` 路径失败，补充路径后重测通过。未进行VSX或实际发射验证。
