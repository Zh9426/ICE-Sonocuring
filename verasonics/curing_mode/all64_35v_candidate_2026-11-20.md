# 全64元、20 mm、35 V离线候选（2026-11-20）

## 已实现

`icec.all64_35v_candidate()` 构建有限、仅仿真的序列及报告，不导出或调用 VSX、不连接硬件。使用全64元、目标 `[0 0 20] mm`、TPC Profile 1、请求电源电压35 V；35 V是原软件设定上限，不是厂家额定或实测值。默认输出仍是内存对象，可通过既有接口独立导出；不得作为上机许可。

其余参数沿用既有 assumed 初值：6 MHz、20完整周期、半周期有效比例0.67、PRI 1000 μs、每组10次、30组、组间10000 μs充电等待。理论burst约3.333 μs，名义局部burst/PRI约0.333%；300次总名义发射包络1 ms。实际编译时间下限约575264 μs，名义总包络/时序下限约0.174%；等待与事件执行均非实测。仿真目标几何不等于实测最大声压位置。

## 未知与边界

这不是最大安全功率版。`max_burst_us`、`max_local_duty_cycle`、`max_total_on_time_us`仍为NaN/unknown；探头型号的发射额定值、实际阻抗、温升、探头与组织允许暴露均未标定。代码使用的50 Ω仅为假设。不能从这组条件推出实际声压、功率、固化或安全，不能由已有 assumed Pa 按35 V推算 MPa。暂不增加burst、半周期有效比例或重复频率，也不推断连续发射可行性。

依据：Vantage NXT Product Specification D00108 Rev. L §1.4 pp.8–9、§3.1 pp.15–17；User Manual D00107 Rev. K §4.4 pp.29–30；Sequence Programming Manual D00163 Rev. K pp.96–97、A154。Profile 1成像电源能力受限制；系统检查保护系统，不保护探头或限定声输出。TPC设定为电源电压，不等于负载端实测峰峰值。Extended Transmit/HIFU是否存在unknown，本候选不依赖它们。Initial Setup Instructions D00109 Rev. D §4.5 pp.9–10描述自检，本轮未执行。四份手册位于本机F盘，跨电脑可能不可用。

下一步先确认探头厂家电压、持续发射/占空比和热限值，确认实际主机/许可、负载与温度监控；由合适设备测量负载电压电流、目标处声压和温升，才能讨论安全边界及功率优化。手册数值不是此探头上机授权。
