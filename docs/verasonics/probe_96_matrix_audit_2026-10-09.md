# 96 元矩阵探头型号证据核查

日期：2026-10-09。结论：本轮没有找到能将实验室实物识别为96元二维矩阵探头的可靠证据。不能据此断言这种探头不存在，也不能否定用户提供的96元信息；实物型号、排布和接线仍为unknown。

## 检查范围与方法

- 静态扫描软件包803个MATLAB源码文件，检索显式96阵元赋值、二维/三维及行列寻址类型；按computeTrans case分支核对阵元数、类型和坐标表达式。不执行SetUp或硬件操作。
- 遍历软件包MAT文件，使用scipy读取顶层Trans；四个v7.3文件另以h5py核对顶层键，分别为主题setting和启动器appInfo，不含顶层Trans。未递归解释所有应用对象，也未解码.p/MEX/DLL。
- 核对XJD、已保存ICE配置、自定义二维阵列示例、SDK探头示例和项目合成配置。
- 外部交叉核对Verasonics官方探头目录与官方产品册；搜索96元ICE及矩阵探头，没有取得与本实验室实物相连的型号证据。网上存在阵列研究不等于实物身份得到确认。
- 类型解释采用项目指定D00163 Rev. K附录A123：type=0线性排列，type=2二维/三维阵列，type=4行列寻址阵列。接口和通道不能代替物理阵元计数。

## 本地源码候选

| 型号或配置 | 源码计数 | 排布证据 | 对96元矩阵假设的支持 |
|---|---:|---|---|
| P4-1 | 96 | type=0，仅x坐标变化；computeTrans第1691行分支 | 只支持96元，不支持二维矩阵 |
| P4-2gH | 96 | type=0，仅x坐标变化；第1792行分支 | 只支持96元，不支持二维矩阵 |
| P9-4ULts | 64 | type=0，仅x坐标变化；第1854行分支；保存MAT一致 | 不支持 |
| Matrix1024-3 / Matrix1024-8 | 1024 | type=2，调用getVermonMatrixElpos；第2344/2365行 | 支持二维阵列，但不是96元 |
| 5RC128 / RC6gV | 256 | type=4，128行+128列 | 行列寻址，不是96个独立矩形阵元 |
| RC15gV | 160 | type=4，80行+80列 | 不支持96元 |
| H-301 / H-302 | 128 | type=2，三维曲面几何及150mm几何焦距 | 不支持96元；不能仅因type=2就叫平面矩阵 |
| H-313 / H-313A | 64 | type=2，三维曲面几何 | 不支持96元 |
| SetUp_Custom_Transducer_2Darray | 128有效阵元 | 16×16位置表内填入1–128，部分位置为0 | 示例而非实物身份；头部256元描述与实际赋值不一致 |
| synthetic_dual_96_config | 每组96，共两组 | 两组12×8，明确synthetic | 合成模型，不是实物证据 |

两份Utilities/computeTrans.m与UserData/Utilities/computeTrans.m均含上述96元分支；重复副本不是两份独立实物证据。803份源码中的显式Trans.numelements=96命中仅来自这两个分支及其副本。动态计算/外部自定义/封装实现不在这一显式匹配结论内。

保存MAT中的顶层Trans只有三项：P9-4ULts（64,type0）及两份L22-14vXULSO（128,type0）。没有找到保存的96元矩阵Trans配置。

## 官方交叉核对

- [Verasonics探头目录](https://verasonics.com/transducers-and-accessories/)：P4-2gH为96元、pitch0.2mm；矩阵产品M3dV/M8dV为1024元、32×32。官方网页型号与旧软件Matrix1024名称不强行认定为同一版本。
- [官方2024产品册](https://verasonics.com/wp-content/uploads/2024/09/Vantage-NXT-Bro-and-Specs-Sept-11-2024.pdf)：区分P4-2gH 96元相控阵与1024元32×32矩阵阵列；没有提供本实验室设备的采购或身份信息。

## 下一步实物核对

获取完整厂家型号/标签、阵元坐标或结构图、引脚映射，以及明确对应实物的工作SetUp。“96元”“相控阵”“二维成像”“Matrix”字样单独出现均不足以证实96元二维矩阵排布。现有64元仿真保留为软件基准，不改名为96元实物预测。
