# ICE 双功能序列核验记录（2026-10-29）

## 核验结论与项目边界

本轮只核验代码、资料和已保存序列，不修改自写驱动或 Vantage 软件包，不运行 VSX，不操作硬件。

现有版本具备可检查的成像/照射事件组织，但仍是**离线序列生成器**；不能据此认定已经满足本支 ICE 探头的硬件限制或可以直接上机。默认事件引用和奇偶阵元掩码在本次保存产物复查中未发现错误；VSX 加载、真实输出、探头电热限制均未获得相应验证。

根据用户本轮确认，合作方体外 FUS 打印已经成功实施。用户研究的是 ICE 器件在该应用中能否实现所需功能，是另一个实验角度/升级途径。材料配方、材料递送、球囊及手术操作不是本研究工作包。后续重点可以转向器件实验；既往仿真用于解释和辅助设计，不将其所有未解问题设为开展器件验证的统一前置条件。

用户目前仅猜测探头为 **TINGSN Sonic Eyes 10 标准版**。因此本次身份状态为 `suspected_standard_10 / unconfirmed`，而不是已确认的 Sonic Eyes 10；不能借用 10 Eco、10 Pro 或其他型号的额定值代替本支探头资料。

## 重点发现

| 编号 | 核验结果 | 证据及影响 |
|---|---|---|
| A01 | **目前不能生成硬件运行模式** | `+icevs/validate_config.m:12-13` 强制 `simulate_mode=1`；设为 0 会报错。入口只构建并导出 MAT/JSON/CSV，没有调用 VSX。应将其定位为离线原型，不能把改一个开关当作完成上机适配。D00163 Rev. K §4.3.2，p25 说明 simulateMode=1 的模拟行为。 |
| A02 | **35 V 不是已证实的探头额定上限** | 原 `XJD/SetUpP9_4TSICE_FlashAngles.m:49` 写入 `Trans.maxHighVoltage=35`，自写 `default_config.m:16` 沿用。未找到本支探头厂家额定依据。D00108 Rev. L §1.4，印刷 p8 / PDF p9 明确区分系统保护与探头过热、损坏及声学输出限制。 |
| A03 | **启动电压发生了明确变化** | 原脚本未定义 `TPC.hv`，原 MAT 也无 `TPC` 变量；自写 `default_config.m:34,40` 对成像和照射均显式请求 5 V。D00163 Rev. K/L §12，p96 说明未指定 hv 时默认 1.6 V。因此未经界面调节的原启动值与自写值不同。原实验运行时是否手动调压未知；此项不证明 5 V 超限，也不能称其为已复现原设置。 |
| A04 | **照射脉冲及等待时间为 assumed** | 6 MHz、20 周期、PRI 1000 μs、每焦点 10 脉冲、30 组，以及初始化 5 ms、换档 5 ms、接收恢复 2 ms、充电等待 10 ms，来自自写配置。没有本支探头长脉冲/热负荷依据；等待时间尚非实测值。 |
| A05 | **固定 5 ms 不能保证所有换档完成** | `compile_events.m` 将换档等待设置为配置值。D00163 Rev. K/L §12.1，p96–97：换档可能需要 800 μs 至 6–8 ms；D00108 Rev. L §1.4，印刷 p8 / PDF p9：涉及 Profile 5 的大压差换档可能达 10–15 ms。默认成像与照射均使用 Profile 1、同为 5 V，不会在两者之间换档；此项主要影响后续异电压/异 Profile 配置，不能说默认序列已出现该故障。 |
| A06 | **Profile 5 支持状态没有成为编译拒绝条件** | `system.profile5_available='unknown'`，校验仍允许照射选择 Profile 5；该状态只写入报告。D00107 Rev. K §4.4.1–4.4.2，p30 和 D00163 Rev. K §12.2，p97–98 说明相关扩展能力是选配。默认没有使用 Profile 5；这是硬件版的待补要求，不是当前默认配置已调用该能力。 |
| A07 | **通道映射继承代码，实物映射未确认** | 自写和既有 `computeTrans` 均使用 1:64、connType=4；原分支还残留另一种映射的注释。执行值与注释应区别对待。`Trans.id=-1` 沿用原脚本，会跳过识别，不能证明探头身份或接线。D00163 Rev. K §13.1，p107、110–111。 |
| A08 | **成像方案已改变，需要单独验证** | 原示例使用全 64 阵元和虚拟顶点发散波/扇形重建；自写默认改为奇数 32 阵元平面波成像及矩形 XZ 重建，偶数 32 阵元聚焦照射。这是设计变化，不能由原示例能运行推导新方案的成像质量、定位精度及功能互扰已验证。 |
| A09 | **尚无探头温度监测或热负荷闭环的实现证据** | 自写函数没有建立温度通道读取、记录及相应停止逻辑，报告也将其标为 unknown。即使某型号具有温度传感器，也需确认本支探头、转接板及 Vantage 路径能否实际读取。D00297 Rev. C，印刷 p3 / PDF p4 的温度故障修复针对已使用温度感测功能的系统，不证明当前配置已启用该功能。 |
| A10 | **每次序列有限，不等于累计暴露受限** | 末尾 `stop` 会进入冻结状态；D00163 Rev. K 附录 A107 / PDF p246 说明解除冻结可从 startEvent 重新运行。300 次照射和软件脉冲上限只描述本次构建/执行；代码没有跨重启的累计发射、冷却或温度状态记录。 |
| A11 | **波形和采样率仍是请求值/名义值** | 手册说明 500 MHz 时钟量化、默认均衡脉冲及可实现解调频率会影响最终参数。当前报告用 cycles/frequency 计算脉冲包络，没有 VSX 加载后 TW/Receive 的实际导出核验。D00163 Rev. K §4.3.1，p23；§16，p121。不能把名义通电时间等同于实际完整驱动时长或声学能量。 |

上述条目中，有些是确定的实现状态/相对原程序的变化，有些是资料缺失或条件风险；不将所有条目称为已发生的代码故障。

## 与既有代码一致或已有软件约束的部分

| 项目 | 结果与边界 |
|---|---|
| 基础几何 | 与包内 `computeTrans.m:1854–1877` 执行定义一致：64 阵元线阵，名义中心频率 6.5 MHz，带宽 [4,9] MHz，节距 0.13 mm，宽度 0.11 mm，高度孔径 2.02 mm，固定高度焦距 30 mm。均是 source-derived，非本支探头厂家核准值。 |
| 成像波形 | 自写 `TW(1).Parameters=[6,.67,2,1]` 与原脚本/MAT 一致。C=2 表示两个半周期，即一个完整周期，而不是两个完整周期。依据 D00163 Rev. K §4.3.1，p23。 |
| 接收模式 | NS200BW、demodFrequency=12 MHz 沿用原配置。12 MHz 在手册允许的该模式范围内；它不等于已证实的最佳接收滤波。不能仅因为发射为 6 MHz 就断言此处是代码错误。依据 D00163 Rev. K §16，p121；还需实际回波验证。 |
| 单位及延时 | 坐标转换为 Trans.frequency 下的波长单位；TX.Delay 按该频率转换为时间。代码检查最大延时不超过 45.5 μs，来源是 D00163 Rev. K 附录 A171 / PDF p310。聚焦延时与厂家数值工具的比较存在于原回归测试中；本轮新执行情况见验证记录。 |
| Profile 电压一致性 | 相同 Profile 不允许成像和照射请求不同电压；TPC.xmitDuration 包含名义脉冲与最大延时。仍需对实际编译波形复核。 |
| 接收缓冲区 | 每次采集预留至少 8192 行，并按 128 行向上取整；多帧缓冲采用偶数帧数。符合已检查的缓冲组织规则。D00163 Rev. K 附录 A101 / PDF p240；D00297 Rev. C，印刷 p3 / PDF p4，Issue 10404。 |
| 纯照射模式 | 已保存 exposure_only 序列没有接收事件，也没有 transferToHost。避开 D00297 Rev. C，印刷 p5 / PDF p6，Issue 7454 所述“有 DMA 但无接收”的已知组合。rcv=0 仅描述事件，不等于已验证接收电路保护或恢复时间。 |
| 软件限值 | 显式填写的 burst/duty/total-on-time/voltage 限值会进行比较；NaN 表示 unknown。默认四项均未知，校验通过不表示探头硬件合格。 |
| UI 及显示依赖 | 本轮实际查看原 MAT 中保留的灵敏度滑块回调：操作 Recon/Control，无需原脚本的局部函数。自写仅保留此滑块，未保留会动态改变深度的原 range 控件；本次未发现这一继承项的缺失函数依赖。Process 使用原 Image.imageDisplay 配置；未执行显示验证。 |

## 形成硬件版之前需要补齐的器件依据

1. **探头和转接器的实物身份**：铭牌/包装/出厂资料上的完整型号；阵元至连接器/UTA 的接线、方向、传感器及接地路径。既有代码能成像是有用的工作基础，但不覆盖全部电热与接线验证。
2. **探头厂家限制**：电压定义及额定范围、允许 burst/周期数、PRF 与占空比组合、连续工作/冷却要求、温度阈值及监测方式、相关阻抗/匹配资料。诊断声学输出限值不能直接替代这些电气额定值。
3. **本机配置**：实际 Vantage NXT 型号、TX/RX 数、UTA、频率配置、安装的软件/固件及许可。Profile 5 只有在实际具备并确认需要时才纳入方案。
4. **原工作序列的实际启动与运行设置**：尤其 TPC 电压、是否经 UI 调节、使用的探头和转接器、原始回波/成像记录。不能由原 MAT 缺省值反推当时实测输出。

这些信息用于下一轮驱动修改和器件实验，不要求用户承担材料及手术方案研究。后续器件验证的顺序可以是：保持可追溯的原工作成像基线，验证指定阵元发射和接收、再验证有限照射输出，最后验证成像→照射→接收恢复。参数值应由器件额定资料和实际测量建立；本记录不指定未经确认的上机电压或照射剂量。
