# 分阶段实验计划

## 1. 软件与数值基线

先运行全部单元测试。检查复数解析值、源幅度线性、延时相位、有限矩形积分收敛、目标体素定义、时序平均和边界输入。`run_convergence` 比较积分小片细分及 ROI 网格细分，输出实际误差与覆盖率变化。不能只因默认图像平滑就声称收敛。

## 2. 三模式和两架构比较

固定阵列几何、频率、源速度、加窗、目标及 ROI，比较 focused、broad、expanded。扩展模式额外记录每个焦点的停留权重和总体曝光时间。先用 shared focused 的空间峰值建立公共阈值参考，再复用它计算所有候选。

在相同 solidification 阵元占比下比较中央、外围、棋盘和随机稀疏分区。报告 C、L、CV、主瓣宽度、次级峰值、活跃面积、最大幅值和平方速度驱动积分。先运行 fixed_element，再运行 fixed_total 作为不同驱动约束的补充；不能把后者写成严格等功率试验。

规则稀疏阵列通过远场角度扫描识别可见的周期性相位重复方向。`run_grating_demo` 使用已知虚拟孔径和转向角验证这一机制。真实焦区的偏轴峰仍由有限距离求解观察，不能仅凭峰的位置自动认定为栅瓣。

## 3. 1D 与 matrix 的受控比较

默认两个示例具有不同孔径与通道数，只用来展示程序功能。正式比较至少分别固定总孔径占地、总发声面积或单元数；这些约束通常无法同时满足，需要明确自变量与资源代价。增加俯仰转向目标，检验单行 ±y 对称与矩阵独立俯仰控制的差异。

## 4. 材料与输出能力闭环

取得材料原始论文/实验记录，确认阈值单位、压力定义、频率、占空比、温度、曝光时间和判定标准。随后测量相同波形下的探头水听器声场，标定表面速度等效幅值或替换为实测声场。阈值覆盖只是筛选变量，需要反应时间曲线验证才可称为固化覆盖。

温度模型暂未实现，因此不评价带 Tmax 的优化目标。先独立保存 C、L 等指标，不用虚构热项拼出总评分。

## 5. k-Wave 与 Verasonics

k-Wave 先做均匀介质小规模基准：明确速度源栅格化、时间步、脉冲、PML、传感器与收敛要求，再与当前 Rayleigh 基线比较。接口目录列出未决字段，当前尚无可执行的 k-Wave 后端。

取得实验室 SetUp 文件后，先离线核对 Trans、TW、TX、Receive、SeqControl、Event 和通道映射。再根据型号文档实现秒到硬件延时单位的映射、发射幅值校准和双模式事件安排。当前仓库不含真实发射脚本。
