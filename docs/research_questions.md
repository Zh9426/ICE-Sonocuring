# 研究问题与证据边界

本项目研究 ICE 导管阵列的声场可控性，为 imaging + ultrasound-triggered curing 双功能方案建立计算底座。当前应用背景是低阈值声响应材料的心腔内封堵，第一阶段交付声学筛选模型。

1. 同一有限孔径下，单行阵列能否覆盖目标，并限制目标外的超阈值区域？单行阵列的俯仰方向只有阵元有限高度带来的被动指向性，没有独立的俯仰延时控制。
2. 矩阵阵列增加第二维延时自由度后，能改善哪些方向的聚焦和扫描？必须分别固定孔径面积、阵元数或驱动条件，不能只凭两份不同尺寸的演示配置声称提升百分比。
3. Shared-element 全阵元时分复用与 Partitioned-element 空间分区如何影响覆盖、轴向/横向宽度及次级峰值？分区减少固化阵元时，也会减少固定单元速度条件下的源驱动。
4. 顺序扫描扩展焦区时，每个位置的瞬时峰值、平均等效强度和实际停留时间如何变化？扫描包络不能当作每个位置持续被照射。
5. 材料阈值到底对应正压、负压、RMS、脉冲平均强度、时间平均强度还是剂量？只有拿到原始定义和持续时间条件后，才能解释超阈值体积与固化的关系。

## 未知信息

真实探头型号、曲率、声透镜、单元尺寸/间距、通道映射、频带、可用电压、热限制、波形、占空比、曝光时间、输出标定、材料“400”的单位与判据均未确认。`config/real_ice_template.m` 明确保留未知值并拒绝运行。平面 side-looking 几何是可配置近似，未声称复现真实 ICE 导管封装。

## 本阶段不形成的结论

不输出真实材料的固化成功率，不预测腔内流动、血液/组织界面、气泡、非线性传播、热场或临床可用性；也不把等效强度或归一化声场当作探头真实输出能力。后续需要真实探头资料、材料剂量实验和水听器测量。
