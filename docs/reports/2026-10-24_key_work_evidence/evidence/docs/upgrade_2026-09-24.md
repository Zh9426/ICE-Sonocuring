# 2026-09-24 ICE 仿真平台 P0-A 升级记录

本次依据研究计划更新，将平台定位从声场演示扩展为**双功能探头架构与局部声学暴露的方案筛选工具**。先形成 [分阶段升级计划](superpowers/plans/2026-09-24-ice-p0-upgrade.md)，随后实施其中 P0-A。2026-09-24 指导文件位于 `D:\ICE_Sonocuring_Codex_Guidance.md`；其中 P1/P2 是未来研究路线，本次没有把它们写成已经实现的功能。

## 已实现的升级

1. `ice.make_probe_geometry` 可将成像和固化两组独立的线/矩阵阵列组合成一个共面探头。各组的阵元数、尺寸、pitch 与平移分别配置，返回互斥的阵元掩码和组编号；若实体阵元重叠或输入非共面偏移就报错。`synthetic_dual_96_config` 提供 **12×8 + 12×8** 的合成例子，不代表现有 ICE 探头的实际排布。旧的单阵列配置仍可运行。
2. `ice.partition_elements` 增加左、右、上、下连续半平面固化分区。`shared` 仍是理论全孔径参考；随机稀疏和棋盘分区保留作数值基线。分区按坐标排序，恰好切断等坐标行时按阵元索引破平局，不能自动保证镜像对称或可布线。
3. `ice.make_sequence` 接受 `single_focus` 与 `focal_scan`/`multi_point_scan`/`trajectory_scan` 等清晰名称，同时保留旧 `focused`/`expanded`。后面三个新名称当前共用**离散焦点逐次发射**实现，绝非连续移动中的瞬态传播。可输入每点 `dwell_time_s`，程序验证秒数之和等于 `exposure_time_s`，并与非空 `dwell_weights` 对照。可选 `pulse_cycles` 与 `prf_hz` 用于检查名义占空比；单频 Rayleigh 声场仍不模拟脉冲频谱。
4. `ice.acoustic_safety_metrics` 在所选三维 ROI 内统计目标外、焦前和焦后的峰值压力、全时段等效强度、超阈值体积，以及目标峰值与目标外峰值比。单焦点时报告目标内**采样峰值**到设定焦点的距离；多点扫描时返回不可定义状态。原来的 x/y 切线之外，CSV 也增加 z 向 −6 dB 宽度，截断时仍为 `NaN`。
5. `ice.check_drive_limits` 将模型阵元峰值表面速度、占空比、曝光时长、总通道数和活动固化通道数与用户**显式给定**的上限比较；输出 `pass`、`fail` 或 `unknown`。它不含电压/功率标定或探头升温，`pass` 不能解读为实际硬件可行。结果保留配置、来源标签、求解器名/版本、网格间距、归一化和阈值定义。
6. `run_p0_probe_compare` 输出两种合成架构的图、CSV 和 MAT 配置；`run_p0_convergence` 额外检查该示例的表面积分小片与体素采样敏感性。

## 合成比较的输入与可解释范围

两例均设 192 个模型阵元，其中 96 个参与固化；频率 2.5 MHz、声速 1500 m/s、密度 1000 kg/m³、未标定峰值表面速度 0.01 m/s、同一 `[2,0,15]` mm 名义焦点、同一目标与 ROI。独立双阵列为两个 12×8 矩阵中心置于 x=−2/+2 mm；分区架构为一个 24×8 矩阵，其中右侧 96 个固化。两者的阵元位置与组间间隙并不完全相同，故指标差不能只归因为“独立双阵列 versus 分区”。

目标是半径 `[1,1,1]` mm 的椭球。ROI 为 x=[−4.5,4.5]、y=[−3,3]、z=[10,20] mm，主运行网格 31×21×31，Rayleigh 表面小片为每阵元 2×2。公共参考是**合成双阵列全 192 元共享发射**的 ROI 峰值 23,084 Pa；图示阈值设为该参考的 25%，即约 5,771 Pa。这个参考与阈值都不是材料实验值；成像阵列参与公共参考发射只用于固定数值标尺，并非实际双阵列工作方式。

| 指标 | 独立 96+96 | 单矩阵右侧 96 固化 |
|---|---:|---:|
| 模型总阵元 / 固化阵元 | 192 / 96 | 192 / 96 |
| 目标覆盖率 C（25% 相对阈值） | 1.000 | 1.000 |
| ROI 目标外超阈值比例 L | 0.13725 | 0.13760 |
| 焦前最大峰压 | 14,524 Pa | 14,458 Pa |
| 焦后最大峰压 | 9,122 Pa | 9,126 Pa |
| x/y 向 −6 dB 宽度 | 3.044 / 4.571 mm | 3.045 / 4.573 mm |
| z 向 −6 dB 宽度 | 不可判定，ROI 截断 | 不可判定，ROI 截断 |
| 设定焦点到目标内采样峰值距离 | 0.674 mm | 0.674 mm |
| 数值驱动限值状态 | unknown | unknown |

图：[独立双阵列声场及掩码](../results/p0_probe_compare/dual_96_plus_96.png)、[连续分区声场及掩码](../results/p0_probe_compare/partitioned_24x8_right_96.png)。原始标量见 [比较表](../results/p0_probe_compare/comparison.csv)，完整配置及逐点场在本机 `results/p0_probe_compare/comparison_config.mat`（MAT 文件按仓库规则不提交）。

这两组结果的全场峰值均落在目标以外的焦前区域；焦后也存在超阈值体素。z 向声束边界未闭合，说明当前 ROI 无法给出完整焦深或证明更远处没有峰。焦点误差是目标内离散网格峰值的位置差，不能直接当作硬件定位误差。驱动状态 `unknown` 是因为没有真实上限与标定。

## 阈值与数值敏感性

[阈值扫描表](../results/p0_probe_compare/threshold_sensitivity.csv)固定上述声场和公共参考，仅将相对阈值在 25%、35%、50% 间切换。双阵列的 C 依次为 **1.000、0.9927、0**，L 依次为 **0.13725、0.04246、0.00569**；分区阵列对应 C 为 **1.000、0.9927、0**，L 为 **0.13760、0.04271、0.00589**。可见“覆盖率”在这个未标定示例中强烈依赖阈值定义，不能从 25% 一档的 `C=1` 推出材料可固化。

[体素细化检查](../results/p0_probe_compare/voxel_check.csv)把双阵列从 21×15×21（6,615 个体素）提高到 31×21×31（20,181 个体素），在 35% 阈值下 C 从 **1.000** 变为 **0.9927**，L 从 **0.04319** 变为 **0.04246**。[局部表面积分检查](../results/p0_probe_compare/surface_quadrature_check.csv)在两个采样点由 2×2 增为 4×4 小片，复声压相对差约 **0.077%** 和 **0.108%**。这只是局部诊断，既未证明整个 ROI 的积分误差上界，也未证明阈值体积已收敛。两架构之间很小的 L 差异不能据此排名。

## 验证与下一阶段

MATLAB R2024b 下运行 `run_tests` 得到 **60/60 通过**；对 39 个 MATLAB 文件运行 Code Analyzer 得到 **0 条警告**。新增测试覆盖组间掩码/重叠拒绝、连续分区、三维焦点相位、停留时间与 PRF 一致性、焦前/焦后体积、空 ROI 状态、驱动限值和双阵列端到端执行。代码保留旧 49 项基线测试。
