# 单点声场结果解读补充

2026-10-22。依据已保存的五组声场及[原验证报告](singlepoint_validation_2026-10-22.md)，另只读回算wide65、fine52的峰值与区域指标；没有新增k-Wave求解、硬件操作或材料仿真。[补充数值](../results/kwave_singlepoint_validation_2026-10-22/interpretation_diagnostics.json)。

当前证据支持假设模型中的局部声学聚集，并表明毫米立方目标的空间选择性需要改善。尚不能判断真实探头是否能固化SonoInk；实际配方、电声传递与材料参数继续unknown。

1. 局部声场对本轮PML、域和网格改变较稳定，但这不是完整收敛证明。wide65全前向压力峰的稳定性条件未通过，需独立保留该负结果。
2. fine52局部压力峰在18.460 mm，目标20 mm处压力仍约为局部峰的95.9%。x/y/z连续压力半幅宽约0.717/2.894/13.477 mm。主问题包含俯仰宽度和轴向长度；把峰移回目标不会自动改善这些宽度。
3. wide65离轴压力峰位于(6.370,0,2.015) mm，其压力高于同工况目标附近局部峰6.76%；但其Qp只有前向域Qp最大值的76.684%。Qp最大值仍在(0,0,18.330) mm。瞬时峰压与累计压力平方积分须分别评价，不能据峰压直接推断离轴温升最大。
4. 固定假设材料盒8×4×18 mm时，1 mm立方目标的Qp积分比例2.160%，材料内目标外/目标内最大Qp为1.0443。这说明当前声学代理没有给出正的最大值选择性余量；不是实际固化体积或能量效率。
5. 对同一fine52场仅将假设材料积分范围改为z=19.5–20.5 mm，目标比例37.098%，目标外/内最大Qp为0.8641。目标积分完全未变。这是分母和区域限制的诊断，可启发固定平面薄层验证，但不证明真实薄层改善了声场或固化。

建议先做因果诊断：在宽域加厚PML并记录离轴点及主焦区的稀疏时序；用更宽域确认峰值位置是否继续变化。然后比较偶数32元与全64元的离线声场，在相同几何、波形和源平方积分预算下检查活动间距效应；另报告同单元幅度结果，避免将填充率改变误认为纯间距收益。6 MHz、假设声速1540 m/s给出波长约0.2567 mm，偶数活动间距0.26 mm，因此栅瓣是待检验候选，而非已证实成因。

随后核实真实俯仰透镜及有效孔径，扫描延时设计焦深但始终保留物理评价目标20 mm；共同评价焦宽、目标覆盖与目标外Qp。最后以明确配方、频段和温度依赖的吸收、热学和聚合数据连接SonoInk模型。声压/阈值、热剂量或任意Arrhenius参数不能直接充当已验证固化判据。当前线性模型中整体增幅会同时放大目标内外Qp，不能独立解决选择性问题。
