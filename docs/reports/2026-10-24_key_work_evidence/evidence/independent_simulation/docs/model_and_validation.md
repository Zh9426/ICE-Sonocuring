# 单点解析基准：模型与验证记录

## 方程和单位

阵元位于 `(x_e,0,0)`，散射点位于 `(x_s,0,z_s)`；理想平面波沿 +z 传播，时间零点是波前通过 z=0 的时刻。所有内部距离m、时间s、频率Hz、声速m/s。

`r_e = sqrt((x_s-x_e)^2+z_s^2)`

`tau_e = (z_s+r_e)/c`

`RF_e(t) = a * (r_ref/r_e) * exp(-(t-tau_e)^2/(2*sigma^2)) * cos(2*pi*fc*(t-tau_e))`

`r_ref=0.02 m`仅用于任意幅度的相对缩放，a为synthetic反射系数。波包是以往返到达时刻为中心的等效带通信号，未单独模拟发射电波形、换能器脉冲响应或接收滤波。理想平面波没有发射端几何扩散，接收端采用assumed 1/r缩放。均匀线性无损介质，点散射体、全向点接收、单次散射；没有阵元有限宽度、方向性、声透镜、吸收、非线性、噪声、多次散射或组织结构。

重建对每个像素计算 `z/c_rec + sqrt((x-x_e)^2+z^2)/c_rec`，对每通道解析RF线性插值并相干求和，取包络和归一化20log10显示。解析信号用FFT Hilbert变换构造，不需要外部工具箱。重建函数不读取真实目标坐标或反射系数；已知目标仅用于事后指标和图上标记。

## 参数来源

| 参数 | 值 | 来源与状态 |
|---|---|---|
| 接收阵元数、间距 | 64、0.13 mm | 原项目软件配置快照，existing_code_unverified |
| 中心频率 | 6 MHz | 原项目发射频率，existing_code_unverified |
| 声速 | 1540 m/s | assumed |
| 发射模型 | 法向理想平面波 | assumed；不同于原ICE虚拟焦点发射 |
| 等效高斯包络sigma | 1/fc | assumed；不代表原TW脉冲形状或带宽 |
| 采样频率、时长 | 48 MHz、45 us | assumed；不是厂商采样量化结果 |
| 散射点 | x=0.830 mm，z=20.030 mm | synthetic；故意不落在重建网格点上 |
| 重建ROI | x=-3..3 mm，z=17..23 mm | assumed局部成像域，间距0.025 mm |

这是数值基准配置，不是实物探头确认；原软件64元与实物的对应关系仍unknown。参数快照记录于JSON；运行时不依赖或执行原项目配置函数。
