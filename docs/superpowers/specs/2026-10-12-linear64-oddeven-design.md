# 64阵元奇偶交替驱动设计

用户本轮明确确认64阵元奇偶交替，并要求生成修改后的成像/固化驱动。本设计将该确认直接落到现有离线构建器。

- 默认沿物理+x从1到64编号，奇数组成像TX/RX、偶数组候选固化TX，各32元。角色方向是assumed软件约定；支持`even_imaging_odd_exposure`互换。逻辑行顺序、连接器编号独立于物理排名。
- 保留完整64项Apod/Delay及原始Trans几何；通过掩码选择孔径。照射事件rcv=0；继续有限时间交替与末尾stop。原始vendor源码不修改、不执行。
- `left_imaging_right_exposure`保留历史回归；synthetic矩阵显式选择该布局，不将线阵奇偶语义扩展到矩阵。
- 新结果使用`results/verasonics_linear64_oddeven`和独立文件前缀；报告schema 4记录编号依据，没有分界线时boundary_x_wls为NaN/null。
- 验收：物理重排和接线倒序不改变物理奇偶；默认及反向角色掩码互补；自定义发射权重不跨区；延时与vendor数学工具对照；三模式保存后检查一致；相关测试及静态检查通过；公告写明尚未执行VSX/实物/声热固化验证。

实施顺序：新增测试并确认旧行为失败 → 增加布局分支和默认值 → 更新历史fixture和导出 → 运行驱动相关测试/生成三模式文件 → 复核图表、源码完整性、文档及空白检查。
