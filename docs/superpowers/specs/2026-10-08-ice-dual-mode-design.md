# ICE 成像与候选固化照射序列设计

用户已确认：以现有 ICE 代码为准，先完成算法驱动改造，后续核实物理参数后集中调整。本设计落实上一轮已经提出并被接受的独立双模式、时分复用方案，不重新要求批准。

## 范围与选择

采用独立 `verasonics/dual_mode` 入口，原厂商 XJD 脚本和 MAT 保持不变。相比直接改原文件，这样可以保留可比基线；相比新写 C SDK，继续使用现成 MATLAB 重建与显示链，减少迁移范围。此轮不实现同时收发、第二支探头或热/材料反馈闭环。

结构为：配置 → 探头/延时 → 波形及图像结构 → 事件编排 → MAT/JSON/CSV 导出。配置支持 `imaging_only`、`exposure_only`、`interleaved`。命名 exposure 表示候选固化照射，不能把发射成功等同于材料固化。

## 基线与新行为

- 基线：P9-4ULts、64 元、pitch 0.13 mm、6.5 MHz 波长单位、6 MHz 成像波形、12 MHz 接收解调、原 15 个角度、30 接收帧、原重建及显示处理。参数来源均为 existing code，实物对应 unknown。
- 新增：独立照射波形、正焦距聚焦及多个 XZ 焦点顺序扫描、每点脉冲数和 PRI、明确功率 profile、双向切换等待、接收恢复和再照射恢复等待、有限会话终止。
- 演示照射参数为 assumed：6 MHz、20 周期、1 kHz、每焦点10脉冲、焦点[0,0,20] mm、5 V供电请求；默认与成像共享 profile 1。它用于检查编排，不声称能固化或适合实物。可显式选择 profile5，但实际选配/阻抗/耐受验证仍是设备工作。
- 默认仅构建和保存，不调用 VSX；保存结构默认为 simulateMode=1、freezeOnStart=1。没有自动激活、固件修改或硬件操作。
- 接收缓冲按请求采样率及范围重新估算并保留余量；真实采样量化与最终内存仍需 VSX 验证。禁用旧的在线 Range 回调，防止它绕过新时序与缓冲检查；保留灵敏度滑块。
- 阵元数不再散落硬编码。变更到96元时必须同时提供96项映射，不能自动把软件序号当接线实测结果。仅支持线性、共面、y=z=0的阵列模型，其他几何须显式扩展。

## 单位与事件约束

配置坐标使用 mm，时间使用 us，频率 MHz；`Trans`、`TX.Delay` 采用以 `Trans.frequency` 为基准的波长/周期单位。成像负焦距延时复现原算法，照射正焦距满足各阵元到焦点的到达时间相同。

事件数有限，末尾使用 `stop`；不会默认无限照射。`transferToHost` 仅与实际成像接收帧关联。profile 切换用非采集事件、显式等待；接收恢复等待与 `timeToNextEB`/储能间隔分开。`noop` 单位200 ns，`timeToNextAcq`单位us。报告的时长/占空比仅表示配置编排和名义波形周期，不冒充实际电波形、输出能量或实测帧率。

依据：D00163 Rev. K §4.3、第96–102页、附录SeqControl/TX；D00108 Rev. L §1.4；随包 D00163 Rev. L 附录 A108 (`noop`/`stop`)。官方 `SetUpL7_4FlashPushP5Mon.m` 仅提供编排思路，其L7-4负载和功率数值不继承。

## 验证

先写探头、时序和集成失败测试，再实现。离线MATLAB检查64/96配置、到达时间与原厂延时对照、三种运行模式、事件索引、恢复等待、无接收无DMA、有限停止、非法PRI与电压请求拒绝、序列保存重读；然后执行已有仿真回归和代码分析。真实VSX与硬件验证不在本轮执行范围。
