# 12×8 矩形阵列固定左右分区修正

用户确认：单个12列×8行、共96元矩形阵列；左6×8用于成像，右6×8用于候选固化照射。这取代2026-10-08的64元线阵共享孔径假设，也不是96+96双阵列。

实施：Trans.type=2，x/y完整坐标；按坐标的左六列生成成像TX/RX掩码，右六列生成照射TX掩码，始终互斥。软件阵元排列采用x最快，与原P0矩形几何一致；ConnectorES独立映射，不把前48编号当成左半阵。照射以三维目标点计算几何延时，成像采用左子孔径平面波复合、三维PData上的XZ切片重建及intensity3D显示。保留有限事件编排、TPC、MAT/CSV导出框架，不保留P9线阵扇区或负虚拟焦距作为实物依据。

阵列拓扑及左右用途来自用户确认；pitch/width/height暂取P0矩形示例0.3/0.25/0.25 mm，标synthetic。频率、阻抗、接线、供电限值及照射参数仍assumed/unknown。可离线检查几何和事件，但本版禁止simulate_mode=0导出，避免未核实接线被误当成硬件配置；不执行VSX。

成像默认重建y=0切片，并不声称完成容积成像。固定物理分区不等于同时收发，仍采用有限交替事件，串扰与恢复需后续实测。矩形单元在VSX中101点轴对称ElementSens不能表达完整二维矩形指向性，使用显式assumed近似并保留尺寸，不宣称已标定。

依据D00163 Rev.K §13.1 pp107–110(type2、ElementPos、ConnectorES、ElementSens)，厂商SetUpM3dVFlash.m的三维PData/切片/intensity3D结构。只参考矩阵对象结构，不继承M3dV的1024路HVMux硬件。

验收：96点12×8坐标；左/右48/48且全覆盖无交集；成像TX/RX无右半权重、照射TX无左半权重；改权重不得跨区；任意接线重排不改变物理分区；非零y焦点到达时间一致且与厂商二维延时对照；3D切片显示结构、有限事件、缓冲与导出回归；重新生成结果并将旧报告标为被取代。
