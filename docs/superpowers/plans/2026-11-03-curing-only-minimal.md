# 纯照射最小驱动及阵元分组实施计划

**Goal:** 单独验证本支ICE探头的固化能力，交付仅含照射的MATLAB SetUp模块及64/48/32/16元四版。

**Architecture:** 沿用现有原版探头定义、聚焦延时、有限事件编译器、TPC和负荷校验，独立构建不含成像/接收对象的序列。四版只改变物理+x排名下的居中连续选元，波形/焦点/时序保持一致；支持任意非空子集。保留simulate_mode=1，不执行VSX/硬件，不把未标定照射初值称为固化参数。

**Tech Stack:** MATLAB R2024b、matlab.unittest、现有+icevs后端、新+icec最小入口。
