## 3. 单次运行记录模板

从任务包创建具体子编号，如 `R006-dual-q4-case01`。下表字段是待采集项，不代表当前已有测量。

| 字段 | 填写内容 |
|---|---|
| run_id / parent_id | 唯一运行编号 / 所属任务包 |
| question / hypothesis | 要检验的命题和反证条件 |
| status / timestamps | planned/running/passed/failed/blocked/deferred；起止时间 |
| git / dirty_diff / solver / environment | 代码提交、未提交差异快照、求解器版本、环境 |
| config / provenance / units | 配置路径/哈希、逐字段来源、单位 |
| target / evaluation_roi / search_domain | 目标与两个物理域，明确边界与网格中心 |
| grid / quadrature / time_step | 空间与积分设置；不适用项写 not_applicable |
| drive / sequence / reference | 幅值/归一化、逐 shot 时间、冻结参考 ID |
| outputs / raw_archive / checksum | CSV/图/完整场/原始数据路径与摘要 |
| metrics / validity / tolerance | 指标、截断/空域/未知状态、门槛 |
| wall_time / peak_memory | 实测耗时与内存；未测写 unknown |
| conclusion / limitation | 仅写数据支持的判断与范围 |
| reviewer / next_action | 复核角色、下一步和恢复条件 |

## 4. 每周复盘模板

- 周次/实际日期：运行时填写。
- 本周新增证据：列运行编号与可点击结果路径。
- 阶段门槛：G0/G1/G2/G3 中哪项通过、失败、未检查。
- 计划偏差：实际工时、计算时间、返工原因与范围变化。
- 下周最多 3 个主任务：对应任务包编号与交付。
- 外部依赖：具体资料/资源、责任角色、需要日期与替代路径。
- 决策：继续、修改或暂缓；证据与对结论的影响。

本文件只有计划状态；正式推进时再填运行记录与通过证据。
