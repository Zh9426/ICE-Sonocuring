# 12×8矩阵物理分区：配置与结果边界

## 依据与参数

96元、12列×8行由用户确认，记为user_reported；实物坐标、接线、几何尺寸和频响未测量。搜索未找到可作为该实物规格的12×8 ICE典型值。

参考：dos Santos et al., *An Ultrasound Matrix Transducer for High-Frame-Rate 3-D Intra-cardiac Echocardiography*, Ultrasound in Medicine & Biology 50 (2024), 285–294，DOI [10.1016/j.ultrasmedbio.2023.11.001](https://doi.org/10.1016/j.ultrasmedbio.2023.11.001)。该文涉及160μm间距、约5–6MHz的ICE矩阵设计，原型16×18，并非本项目12×8。论文的电声效率、ASIC或通道缩减不移植为本探头参数。

本轮采用160μm双向间距、6MHz作为literature-inspired assumed值；140×140μm矩形有效阵元、3.6MHz高斯带通宽度、20周期、1Pa参考压力源、目标(0,0,20)mm均assumed。全阵物理跨度约1.90×1.26mm；左右子阵分别0.94×1.26mm，中心x=±0.48mm。如此小的孔径不保证20mm处形成紧凑焦斑。

介质：1540m/s、1000kg/m³，均匀无损线性assumed；无压电固体、匹配层、挡板、声透镜、声学耦合及电串扰。没有将电压转换为实物声压，不计算固化。

## 几何、分区和求解

- 配置：`+iceind/matrix96_config.m`；模型：`matrix96_model.m`。编号沿x优先，然后y，仅供仿真，不是实物连接顺序。
- 左/右按阵元中心x正负分组，各48元，互斥且覆盖全部阵元。上下48+48也可生成，但本轮只运行左右。
- 每区独立发射，相同单阵元波形/幅度。延时为 `(max(distance)-distance)/c`，确保中心几何传播在指定点同时到达。该条件不保证空间压力全局峰值恰在设定点。
- 有限矩形源按网格单元面积重叠离散，包含各自x和y偏移；k-Wave additive压力源。采用原独立工具的assumed滤波PWM波形，不调用厂商SetUp、VSX或硬件。
- R2024b + k-Wave1.4.1 `kspaceFirstOrder3D`。64μm网格、CFL0.2，域10.24×10.24×25.6mm，PML在外厚1.28mm。源位于域后端前0.64mm；保存z轴以阵面为0。
- 不复用64元线阵声场；无新的实物96元SetUp或Event翻译，因为正确硬件配置仍unknown。

## 运行和输出

在独立目录用R2024b执行 `run_independent_tests; run_matrix96;`。默认仅left/right，两区分别求解。可显式调用 `run_matrix96('full_reference')` 作为全孔径参考，不代表改变物理分区；本轮默认不运行。

结果在 `results/matrix96/`，与64元结果隔离：

- `left/right_dx64.0um.mat`：完整网格peak_abs、p_max_all/p_min_all、传感器p(t)、坐标、延时、分区、配置与报告；时间轴由report.dt_s/Nt恢复。不是完整四维p(x,y,z,t)。
- `.json`：压力、时间、网格、来源和ROI截断标记。
- `.fig`：MATLAB可旋转三维等值面及XYZ切片；使用 `openfig(...,'visible')` 查看。
- `.png`：静态预览。MATLAB图每个分区使用自身ROI峰值，切片色标独立，不能仅凭颜色比较幅度。
- `export_matrix96_view.py`：用Python(h5py/numpy/plotly/scikit-image)读取两份MAT，生成自包含离线HTML三维查看器和comparison.json。HTML两区使用共同ROI峰值作为等值面基准，可旋转、缩放和隐藏等值面。

三维面为全时间窗max|p|的-3/-6/-12dB等值面，不是同一时刻波前。ROI视图仅为显示按2倍步长采样并裁剪至z=12–24mm；HTML另提供按3倍步长显示的全前向场(z>=0)，以两区共同全域峰值归一化。HTML的XY切片可在12–24mm间移动。全分辨率完整域数据保留在MAT。等值面触及ROI边缘时不可当封闭焦斑或计算完整焦域体积。

记录源波形平方时间积分代理量用于检查两区驱动一致，不等于电功率、声能或声强。实际声能流需要相应压力与粒子速度及边界定义。

## 验证

测试包括96坐标及12/8唯一坐标数、左右完整互斥分区、等到达时间与镜像延时、重叠阵元拒绝、每阵元面积保持及y位置参与映射。首次测试因缺少实现失败，补充实现后15/15独立测试通过；日志 `results/matrix96_tests_before.log` 和 `results/matrix96_run.log`。

左右场镜像对照是内部检查，不是独立物理验证；64μm单网格尚未收敛验证，原64元两网格比较不能转用于本模型。尚需计算域/PML敏感性、声源离散化与更细网格检查。任何边界峰值须明确报告，不宣称已证明聚焦最佳或左右分区最优。

## 本轮实际结果

R2024b完成左右两区，求解调用分别306.69秒和304.51秒，求解器报告显存约2.59GB。网格160×160×400，外加PML后200×200×440；时间步8.3117ns，共2746步。6份新增MATLAB源码Code Analyzer均0消息；Python MAT轴顺序测试通过，Python导出脚本编译与实际导出成功。`git diff --check`无空白错误。HTML已生成含离线Plotly资源，浏览器工具禁止file协议，因此未进行浏览器交互实测；MATLAB生成的左区PNG已目视检查。
