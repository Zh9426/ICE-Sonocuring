# 全64元偏转聚焦仿真实施计划

按独立仿真目录规则，本计划保存在 `independent_simulation/docs/plans/`。

**Goal:** 按用户2026-11-19授权，运行固定中心至目标20 mm、0/±10/±20/±30°平面内偏转，首要比较焦区范围。

**Architecture:** 保持原64元同幅BLI声源和实际导出几何，改变目标与几何延时。使用同一扩大物理域、52 μm网格、均匀无损假设及CUDA求解器。分析主焦区的压力−6 dB与−3 dB六邻域连通分量、体积和旋转方向宽度，同时报告截断和目标外最大值。

**Tech Stack:** MATLAB R2024b、k-Wave MATLAB 1.4.1、社区CUDA v1.4.2发布包、Python NumPy/SciPy/h5py/Matplotlib。依赖仅本机，不随Git同步。

## 数值适用范围

每元1 Pa assumed、6 MHz既有波形、声速1540 m/s、密度1000 kg/m³；焦区是相对声压分布范围，不是固化区。52 μm单档不证明网格收敛，源面敏感性继续披露；角度为探索工况，不是实物额定范围或真实左心房/左心耳测量。末帧仅用于发现明显截时，不能独立证明时间窗收敛。无VSX和硬件操作。
