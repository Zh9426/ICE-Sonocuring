# 本轮结果说明什么，下一步解决什么

2026-10-23。依据[边界诊断](offaxis_diagnostic_2026-10-22.md)及[活动阵元对照](aperture_control_2026-10-23.md)；下述均为assumed无损流体、未标定矩形压力源下的声学结果。

## 已取得的证据

1. PML16→20格及X物理域15.6→16.64 mm两项有限改变，完整公共域峰压场L2差约0.077%和0.022%，原z≥2 mm搜索峰位不变。不支持这两个边界设置是原浅层结构的主要成因；仍不是全空间或宽域细网格收敛证明。
2. 同源端压力平方-面积-时间代理预算B下，全64元统一缩放0.707106781。原固定离轴点/固定主焦点Qp比从0.766925变为0.000373。该结果与活动配置显著相关，但数量、间距、填充率、孔径和中心一起变化，不能唯一归因pitch或直接证明真实探头栅瓣。
3. 改善不限于原测点，但也不是全部浅层暴露消失：0<z<2 mm区域最大峰压2.221→0.900 Pa；2≤z<5 mm最大值1.502→1.108 Pa。区域最大值与固定点变化必须分开；这些压力值均沿用assumed源，非实测声压。
4. 主焦区峰值仍在(0,0,18.395) mm，20 mm名义目标仍存在约1.6 mm焦前偏移。固定目标点/固定主焦点Qp比两配置均约0.917，显示这两个点间的轴向选择性未明显改善。尚未重新计算全64元的全域Qp或厚材料积分比例，不能声称此前1 mm目标选择性问题已经解决。

固定测点取最近体素：名义20 mm目标实际采样z=20.020 mm；固定主焦点z=18.395 mm；固定离轴点(6.370,0,2.015) mm。旧32元Qp来自GPU RMS估计，新64元来自保存p(t)的双精度直接积分；约0.01%尺度的微小差异含计算口径误差，不作物理排名。

## 下一步优先级

- **先补宽域细网格对照。** 原52um域不含该离轴点，不能将旧局部网格检查当作这次浅层结构及其抑制效果的收敛证据。保留32/64对照和相同源预算定义，不缩小搜索区掩盖峰值。
- **再处理焦深与俯仰模型。** 物理目标保持20 mm，扫描延时设计焦深建立“设计焦深→实际峰值”映射；同时评价焦宽和目标外暴露。核实真实俯仰孔径/透镜，不能把一维阵元延时优化当作独立Y向聚焦能力。
- **材料接口明确后再接SonoInk。** 需要具体配方、实际材料/容器几何、吸收随频率/温度变化、热学与反应判据及声压标定。B不是实际声功率，Qp不是吸收热量或固化；当前结果不能导出上机驱动处方。

当前证据足以重新评估固定偶数32元照射方案的声学代价。全64元仍是synthetic离线候选，保存SetUp和原硬件角色均未改变；未进行VSX、硬件或材料实验。
