# 纯照射四版三维声场比较（2026-11-12）

## 范围和执行

应用户要求，在既有 All64、Center16 完整场基础上，以同一方法补算 Center48、Center32 各 65/52 μm。既有64/16是2026-11-11实际结果，本次没有重复传播；48/32四个新工况实际在 MATLAB R2024a Update 9、k-Wave 1.4.1 和社区 CUDA v1.4.2（程序报告 kspaceFirstOrder-CUDA v1.3 build 3.6）运行。运行命令：`matlab -batch "addpath(fullfile(pwd,'independent_simulation')); curing_run_center48_center32_20261112;"`；生成比较：`matlab -batch "addpath(fullfile(pwd,'independent_simulation')); curing_compare_four_20261112;"`。均为离线模拟，不运行 VSX 或硬件。

四版从各自实际导出的 MAT 取得选元及 TX.Delay：物理位置排序分别为1–64、9–56、17–48、25–40，活动孔径依次为8.30、6.22、4.14、2.06 mm。所有活动阵元采用同一假设源信号、6 MHz 20周期波形及相同源滤波，未按阵元数进行归一化；阵元数和孔径同时变化。介质假设均匀、线性、无损：声速1540 m/s、密度1000 kg/m³，域15.6×10.4×31.2 mm、PML 1.04 mm、源偏移0.52 mm、CFL 0.2、时窗40 μs。模型使用平面矩形阵元、没有真实俯仰透镜。单发 `Qp=∫p²dt` 并非实际声能或热量；幅值与探头声压均未标定。

前向峰按现有 `z>=2 mm` 区域定义，分别比较目标盒内、目标盒外后选取最大者；在本四版这些值均与表中所列深度一致。目标点与各版自身前向峰之比按 `20 log10(p_target/p_peak)` 分别约为 −0.38、−1.01、−3.00、−8.17 dB。盒外最大值与盒内峰相近时不应自动称为独立旁瓣：例如48元是连续轴向高值带跨越盒的浅侧边界。

固定目标盒为x/y各±2 mm、z=16–24 mm。其最大值位置分别是 z=18.460、16.380、16.016、16.016 mm；后两者位于盒浅侧边界，不能称为目标处的独立焦点。穿过目标盒内峰、按声压幅值−6 dB求交点的 x/y/z 宽度（mm）分别为：64元 0.715/2.887/13.411；48元 0.876/2.571/26.553；32元 1.214/2.503/无法完整测得；16元 2.383/2.499/无法完整测得。32/16元的宽度是围绕目标盒边界峰的剖面，仅为剖面量，并非已确认焦斑；其轴向交点被计算域截断。没有预设打印需求的焦点偏差或宽度阈值，本研究不下正式合格/不合格结论。

同一目标源信号下，64元在目标附近表现出最集中的模型主峰；48元目标点仍位于较强区域，但轴向高值带较长；32元主峰移到约11.2 mm，目标深度仍有声压但并非独立主峰；16元主峰移到约5.1 mm，目标处相对自身峰更弱。对实际打印的适用性取决于打印材料阈值、期望空间分辨率、实际标定声场及实验验证，本次没有确定这些参数。

## 网格敏感性、验证与限制

65→52 μm源面Qp原生峰变化分别为 All64 +8.97%、Center48 +3.04%、Center32 −1.51%、Center16 −6.10%；64和16仍超过5%内部数值诊断阈值。48/32目标盒共同260 μm采样点的压力相对L2分别0.265%/0.255%，Qp分别0.111%/0.112%；共同格点可能漏掉原生峰，不等同于全面收敛。48/32近源 `0<z<0.26 mm` 的Qp原生峰变化分别+0.267%/−3.751%，计算时以1e-12 m容差排除源面浮点误差。64元更细网格源面结果和插值局限见 `independent_simulation/docs/gpu_deployment_2026-11-11.md`。

本轮测试 `curing_field_test_cases`、`curing_field_test_bli_prepare`、`curing_field_test_gpu_analyze`、`curing_field_test_bli_compare` 共16/16通过。首次测试汇总命令因数组维度拼接出错，修正后完整重跑通过。48元65 μm初次MATLAB调用未生成输出；在不覆盖输入的情况下直接运行CUDA成功，随后正式重跑成功。失败根因未知，原始诊断输入输出保存在本机 `center48_dx65_direct_diagnostic_20261112/`；运行脚本现保存失败日志后再抛出异常。Sol独立核对四个新算例的驱动选元和延时、GPU输入、原始HDF5到MAT全量数组及指标；48元65 μm直接运行与正式输出四个数组逐元素一致。末帧值较小不能单独证明时窗收敛。

完整原始MAT/HDF5、每版图、剖面、两档对照和统一表在 `independent_simulation/results/curing_field_2026-11-10/bli_gpu_full/`；脚本为 `curing_gpu_run_case_20261111.m`、`curing_gpu_analyze_20261111.m`、`curing_compare_four_20261112.m`。依赖位于Git忽略目录，另一台电脑须重新部署。源面敏感、无俯仰透镜、未标定和时窗未充分独立收敛等限制保留，不作实际声功率、温升、固化或安全结论。
